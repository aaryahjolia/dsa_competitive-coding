# Git, without the mystery

Welcome to the little Git learning path. The original notes are still here in [`01_Intro.md`](01_Intro.md); these companion guides reshape the ideas into shorter, friendlier lessons and add examples for everyday use.

## Pick a lesson

1. [How Git remembers your work](02_How_Git_Remembers.md) — snapshots, commits, branches, and Git’s history graph.
2. [Your everyday Git rhythm](03_Everyday_Workflow.md) — check changes, stage the right things, and make commits.
3. [Branches, merges, and rebase](04_Branches_Merges_Rebase.md) — experiment safely and bring work together.
4. [Git commands and remotes](05_Commands_and_Remotes.md) — collaborate with GitHub or another remote, plus a handy command shelf.

The examples use `main` for the primary branch. Older repositories may call it `master`; use the branch name your repository actually has. Commands that can discard local work are marked clearly, so you can check before you run them.

> Tiny Git mantra: check what changed, stage what you mean, then commit with a message your future self will understand.
